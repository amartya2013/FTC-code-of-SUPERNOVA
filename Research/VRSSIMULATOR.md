# 🤖 VRS Simulator

### FTC Programming Quick Guide

**🔹 What is VRS?**

* **VRS = Virtual Robot Simulator**
* Practice FTC programming **without a physical robot**
* Supports **Java & Blocks**

**⚙️ Robot Basics**

* Use the **exact hardware names** configured in VRS
* Our tank-drive robot:

  * `frontLeft`
  * `frontRight`
* If the robot spins, **reverse one motor**

**🎮 TeleOp vs. Autonomous**

* **TeleOp:** Driver controls the robot
* **Autonomous:** Robot follows programmed instructions

**💻 Programming Basics**

* Use functions such as:

  * `forward()`
  * `backward()`
  * `left()`
  * `right()`
* Use **Telemetry** to see what the robot is doing

**📏 Making the Robot Accurate**

* **Power + Time:** Basic movement
* **Encoders:** Accurate distance & turns
* **Sensors:** Help the robot react to its environment

**🚀 Learning Path**
**Motors → Movement → Turns → Functions → Encoders → Sensors → Autonomous**

**⭐ Team Rule**

> **Test one thing at a time. Understand why it works before making it more complicated.**
